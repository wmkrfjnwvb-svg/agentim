# Security policy

Please report security problems privately, not in public issues:

- **GitHub:** [Report a vulnerability](https://github.com/wmkrfjnwvb-svg/agentim/security/advisories/new) (only maintainers see it).
- **Email:** security@agentim.co (AgentIM Cloud, or if you can't use GitHub).

We confirm reports within 3 business days, assess them within 10, aim to fix critical and high problems within 30 days, and publish an advisory with the fixing release, at the latest 90 days after the report unless we agree otherwise. The latest release gets security fixes.

Scope, safe-harbour terms and details: [Reporting a vulnerability](https://agentim.co/docs/security/reporting/).
