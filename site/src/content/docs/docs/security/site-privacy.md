This website (agentim.dev) is a static site.

- **No analytics, no tracking, no advertising.**
- **No cookies** and no local storage, except your choice of light or dark theme, kept in your browser.
- **No third-party scripts or fonts.** Everything is served from this site.
- The site is hosted on GitHub Pages. GitHub receives the usual request data (such as your IP address) to serve pages and keep the service secure; see the [GitHub Privacy Statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).

The chat window on the homepage is a recording that runs in your browser. Nothing you type in it is sent anywhere.

AgentIM itself is software you run. What it stores about your users is described in [GDPR and data rights](/docs/security/gdpr/) and is under your control.

Questions: open an issue on [GitHub](https://github.com/wmkrfjnwvb-svg/agentim/issues).
