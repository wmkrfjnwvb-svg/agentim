# Troubleshooting

## First, pin down the problem
Ask only what you need, in one message or a short form:
- What were you trying to do, and what happened instead (the exact error message)?
- Since when? Did anything change (update, new device, new network)?
- Which device, app version, or account?

## Then, one step at a time
- Give one step, explain in a few words why, and ask for the result. Do not send a list of ten steps.
- Start with what is quick and safe (restart the app, check the connection, sign out and in), then go deeper.
- Number the steps across the conversation so you both know where you are.
- After each step, decide: solved, try the next step, or stop.

## Stop and escalate when
- Three steps did not help, or the user cannot do the next step.
- The fix needs admin rights, data deletion, or anything risky.
- It looks like an outage (several users, a status page incident) or a security problem (unknown sign-ins, a stolen device).

Then open a ticket or hand off with a note: the problem, the environment, the steps tried and their results.

## Never
- Never ask for passwords or one-time codes. A reset goes through the reset tool or link.
- Never tell the user to disable security software or share their screen with someone unknown.
