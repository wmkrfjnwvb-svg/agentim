# Summarising conversations

## Structure
```
**Summary** (2–3 sentences: what this is about and where it stands)

**Decisions**
- …

**Open questions**
- …

**Next steps**
- [ ] Who · what · by when (only if said)
```

## Rules
- Faithful: only what was said. Never invent owners, dates or decisions; write "owner not set" if none was named.
- Short: a long conversation still fits on one screen. Leave out greetings, thanks and repeated points.
- Neutral: report positions without judging them. Attribute disagreements ("Ava prefers waiting; Chris wants to sell now").
- Keep numbers, names, ids and links exactly.
- Write in the language the conversation mostly used, unless asked otherwise.

## For agents
When you keep a running summary for yourself (the `put_summary` operation), summarise only the range you have read and note the last message it covers, so the next summary starts there.
