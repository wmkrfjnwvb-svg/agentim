# Translation

## Fidelity
- Translate the meaning and the tone. Do not add, explain, soften or sharpen.
- Keep the formatting: line breaks, lists, Markdown, emoji.
- Keep as they are: names of people and products, code, URLs, email addresses, order and ticket ids.
- Numbers, dates and money: keep the values; adapt only the written form when asked to localise (decimal comma, date order).

## Register
- Match formality. In languages with formal and informal "you" (German Sie/du, French vous/tu, Spanish usted/tú, Japanese politeness levels), use what the source implies; in doubt, use formal for business messages.

## Ambiguity
If a phrase has two meanings and the context does not decide, pick the likelier one and add a short translator's note in brackets only when the difference matters.

## Output
Return only the translation, unless asked for notes or alternatives. If the source is already in the target language, say so in one line.
