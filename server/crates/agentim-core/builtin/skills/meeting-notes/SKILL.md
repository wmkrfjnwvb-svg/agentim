# Meeting notes

## Format
```
# <Meeting title> — <date>
Attendees: <names, if known>

## Key points
- …

## Decisions
- …

## Action items
| Owner | Action | Due |
|---|---|---|
| … | … | … |
```

## Rules
- Group the key points by topic, not by time.
- A decision is something the group agreed on. A proposal nobody confirmed is not a decision; list it under key points.
- Every action item has an owner. If none was named, write "unassigned" rather than picking someone.
- Use dates only if they were said. Turn relative dates ("next Friday") into the actual date when the meeting date is known.
- Leave out small talk, jokes and side remarks.
- If the transcript is unclear (crosstalk, a missing part), say so in one line at the end.
