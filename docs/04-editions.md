# 04 版本划分

> 状态：草案 v0.1（2026-10-10）

## 1. 原则

- **开发者能用到的全部开源，只有"组织"才需要的能力收费。**
- 开源自托管无法按用量（MAU、并发）收费，因此社区版按**功能**分层，不设规模限制；用量计费只适用于未来的托管云。
- 安全护栏属于基础能力，免费版即具备。
- 企业功能通过 trait/插件实现（见 [02 架构](02-architecture.md#52-开源核心接口)），核心代码不出现企业版分支。

## 2. 功能矩阵

| 能力 | 社区版（Apache 2.0，免费） | 企业版（商业授权） |
|---|---|---|
| **消息核心** | 可靠投递、会话内有序、单聊、群聊（含 10 万人大群）、线程、回执、已读、离线同步、多端 | 同左 |
| **规模** | 单机到集群全部可用，不限人数或连接数 | 多地域部署、跨机房容灾、零停机升级 |
| **AI 原生** | 流式消息、取消与打断、Agent 成员、工具调用事件、内置 MCP Server、基础上下文检索 | 同左 |
| **AI 安全护栏** | 跳数上限、速率与预算上限、循环熔断、注入检测基础规则 | 自定义规则、组织级策略 |
| **人工介入** | Agent 所有者管理自己的 Agent（观察、打断、接管、审批） | 主管角色跨团队观察、耳语、接管；多级审批工作流 |
| **AI 治理** | 单一全局 API Key、基础限流 | token 计量与成本归属、按用户/组/团队授权模型、工具调用审批策略、Agent 访问范围、提示词护栏、敏感数据过滤 |
| **身份** | 账号密码、OAuth（Google/GitHub）、2FA | SAML SSO、SCIM、LDAP/AD、细粒度管理员角色 |
| **合规** | 基础消息导出 | 审计日志、数据保留策略、法律保全、eDiscovery 导出、数据驻留、HIPAA 支持 |
| **运维** | Prometheus 指标、基础管理后台 | 运维控制台、高级监控、托管部署工具 |
| **互通** | 开放协议、Webhook | A2A 网关、Slack/Teams 桥接 |
| **服务** | 社区支持 | SLA、7×24 支持、专属技术支持 |

## 3. 未来：托管云

- 架构已预留多租户（`tenant_id` 进入消息模型与分片键）。
- 托管云按用量计费时，计费单位应为**合并后的消息**，而不是 token，避免流式流量导致成本失控。

## 4. 风险

Apache 2.0 允许任何人（包括云厂商）直接托管本项目。护城河依靠：迭代速度、社区、企业功能、品牌（商标）。
