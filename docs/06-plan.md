## 0. 一页看全局

**方向**（2026-10-18 确认）：只服务开发者；一个产品、一个程序 `agentim`，全部功能免费；已做完的 Agent 能力全部保留，没开始的 Agent 中间件不做；下一阶段做开发者体验闭环：发现 → 5 分钟跑起来 → 30 分钟嵌进自己的应用 → 用开发者控制台管理 → 付费（托管云或支持服务，D102）。

**当前位置**：消息核心、开发者接入、AI 部分（L1–L7）和集群（C0–C4）已经完成。下一步按 §3：先做 D105（合并 Lite 和 AgentIM）和几个小修复，然后是发布、TypeScript SDK、React 组件、开发者控制台、文档站和示例。每一项都先写设计、你确认后再写代码；开发者体验的设计见 [12](12-developer-experience.md)（待确认）。

**测试**：全部通过。CI 每次推送跑：Linux 和 Windows 上 SQLite、PostgreSQL、MySQL 的全部测试，多节点集群测试，真实数据库主从和切主测试，Docker 镜像和三节点 Compose 冒烟，浏览器冒烟，压测，服务端和 Agent SDK 的端到端；规模测试夜间跑。

### 1.2 已确认

**产品和范围**

| # | 事项 | 结果 |
|---|---|---|
| 定位 | AgentIM 是什么 | 给开发者的、AI 原生的聊天基础设施：任何框架写的 Agent 都能作为成员接进来，持久、有序、多方、可治理（[01 §1](01-product.md)） |
| 方向 | 2026-10-18 调整 | ① 只服务开发者（独立开发者、创业团队、给自己产品加聊天和 AI 助手的 SaaS 团队、集成商），不再以企业 IT 和合规团队为目标用户；② 不分社区版和企业版，不做授权文件；③ 没开始的 LLM Agent 中间件全部不做：工具网关、审批 v2、Claude Code / Codex 远程审批、A2A 网关和跨服务器联邦、服务端托管 Agent；已做完的 Agent 能力全部保留；④ 合并 Lite 和 AgentIM，只保留一个程序 `agentim`（D105）；⑤ 下一阶段做开发者体验闭环（[12](12-developer-experience.md)）；⑥ 集群保留，免费、不限规模 |
