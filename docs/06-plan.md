| D59 | 是否记录提示词和回复 | **默认不记录**，只记用量和元数据；可以按部署或按 Agent 打开，用 Agent 的数据密钥加密，默认保留 7 天、最长 30 天 |

| B4 | **静态加密开启后再改成 `off`，已加密的内容读不出来**（报 `storage` 错误）；先关后开没有问题 | 改为：`off` 时只要配了主密钥就照常读旧密文、新内容不加密；加 `encryption decrypt-existing` 命令；没配主密钥但库里有密文时拒绝启动并说明原因。随 A4 一起做，测试覆盖开 → 关 → 开 |
