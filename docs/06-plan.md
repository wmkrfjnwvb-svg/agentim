**B. 集群**（设计见 [11](11-cluster.md)，依据见 [调研](research/cluster.md)）

| # | 事项 | 我的建议 |
|---|---|---|
| D72 | 集群时文件存在哪里 | 默认存进数据库（按块），集群不需要额外组件；文件多的客户切换到 S3 兼容存储 |
| D73 | 租约的时间参数 | 租约 15 秒、续约 3 秒、单次数据库操作超时 2 秒、自停 10 秒（参考 client-go 的 15/10/2 和 Patroni 的约束）；节点崩溃后约 15–18 秒接手。压测后再调 |

| D75 | 读取水位线管到哪里 | 读会话记录的路径（同步、历史、搜索、上下文）必须只返回已确认复制的部分；成员列表、未读数等状态读取允许在数据库切主瞬间短暂不一致，切主后由同步协议修正 |

| D78 | 新增一个可重试的错误码 | 新增 `unavailable`（带 `retry_after`），用于：数据库切主中、从库确认超时、分片正在交接、转发超时。现有的六个码都不合适：这不是限流，也不是业务冲突 |
| D79 | 测试是否引入 Java（elle-cli 检查器） | 每次推送的 CI 用我们自己用 Rust 写的检查器；elle-cli 只放在夜间任务里作为第二道检查 |
| D80 | 每个数据库的分片数 | 256，初始化后不能改（Temporal 也是这样）；够 50 个节点以内均匀分布 |
| D81 | 自停窗口内的非持久副作用（正在输入、流式增量、在线推送） | 允许短暂重复或丢失（客户端本来就能处理）；写入的正确性不受影响 |
| D82 | 要不要进程级看门狗（Patroni 用硬件看门狗） | 不要：我们有数据库层的代号校验，正确性不依赖进程及时停下；用健康检查 + 连续续约失败时主动退出 |
| D83 | Windows CI 的数据库 | 补上 PostgreSQL 和 MySQL（用 Windows 镜像预装的数据库），满足 CLAUDE.md；数据库主从切换的测试只在 Linux 跑（GitHub 的服务容器只能在 Linux 上用） |
| D86 | 数据库切主丢了数据时怎么办（[11 §8.5](11-cluster.md)） | 服务默认进入恢复模式启动，自动检测和修复；倒退的会话更换纪元，客户端按消息编号对账、**不删除本地记录**，自己的消息补交找回；彻底重建的会话把本地记录**归档到只读的旧记录区，提示用户并可导出到本机**；误接回旧主库时需要管理员执行 `accept-rewind` 确认 |
| D84 | 集群在 MVP 里的位置 | C0（单机也受益的加固和接口）提前做；C1–C3 放在 CLI 和管理 API 之后；C4 和部署发布一起做（§3） |

### 1.2 已确认

**产品和范围**

| # | 事项 | 结果 |
|---|---|---|
| 定位 | AgentIM 是什么 | 任何框架写的 Agent 都能接进来的、持久、有序、多方、可治理的通信和记录层。秒迁移，随时销毁（[01 §1](01-product.md)） |
| 产品线 | AgentIM Lite 和 AgentIM | 一个仓库、一个核心、两个程序；Lite 完全开源免费，AgentIM 分社区版和企业版；**先做完 Lite 再做 AgentIM**（[01 §6](01-product.md)） |
| D70 | 收费点 | **安全、合规、审查**，以及组织级的 Agent 治理（2026-10-12）。规则：个人和小团队"合法、安全地用起来"需要的免费；组织"管得住、查得到、证明得了"需要的收费；法律和应用商店要求的（GDPR 基本权利、举报、拉黑、AI 标记）永远免费；基础 E2EE 免费。对照表见 [01 §7](01-product.md) |
| D69、D71 | 集群 | **免费**，所有版本都有，不限规模（收费另找途径）。方案已确认（2026-10-12）：**除数据库外不依赖任何组件**（不用 Redis、etcd、ZooKeeper、Consul）；节点平等，没有主从；会话按固定数量的虚拟分片由**数据库租约**决定归属，**没有选举**（数据库条件更新，先抢到的赢）；每批写入在同一事务里校验租约代号；节点之间全互连（和 Redis Cluster 的总线类似，但成员和归属以数据库为准，不用投票）；数据库有异步从库时由我们等从库确认；做成独立的 Rust crate，测试分单元、模块、功能、异常、边界、负载六层。设计见 [11](11-cluster.md)，细节待 D72–D84 |
| D85 | 文件和音视频 | 都放在 **MVP 最后**做（没有它们 IM 不完整）；音视频集成 **LiveKit**：我们做呼叫信令、权限和入会令牌、通话记录、离线来电推送，LiveKit 做媒体转发、录制、通话加密和 Agent 入会 |
| D68 | 工具网关和 A2A 网关 | **都做，进 MVP，所有版本都有**（Lite、社区版、企业版）（2026-10-12）：这两个才是我们的价值。工具网关的含义：**Agent 调用工具必须经过 IM 授权**（远程工具由 IM 保管凭据、代为调用，能强制；Claude Code、Codex 的本机操作通过钩子接入同一套授权和审批，企业托管设置下能强制）。跨服务器的 Agent 联邦跟着 A2A，也是所有版本都有 |
| D54 | 模型网关 | **不做**（2026-10-12）：LiteLLM、Portkey 等已经成熟，没有差异化。Agent 可以上报用量（[10 §6](10-agent-ecosystem.md)） |
